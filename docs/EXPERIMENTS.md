# 頭アンカーの実験指針

## 最初に用意するもの

まず実VRMを3体、余裕があれば5〜6体用意します。同じモデルを拡縮しただけの比較と、作者・骨・メッシュが異なる比較を分けます。モデル本体はこの公開リポジトリへ入れません。

| ID例 | 用途 | 準備の優先度 |
|---|---|---|
| A01 | これまで問題なく使えた標準体格 | 必須 |
| A02 | 今回前へずれた小型アバター、その実ファイル | 最優先 |
| A03 | 別作者・別エクスポーターの標準人型 | 必須 |
| A04 | 大きな頭・髪・帽子など頭頂形状が違うもの | 追加 |
| A05 | 大型／極端な等身 | 追加 |
| A06 | 未確認のVRM世代（0.x／1.0を両方含める） | 追加 |

VRM世代・作者・エクスポーターは分かる範囲で記録し、不明を推測で埋めないでください。本人が扱える素材を使用します。

## 手順

1. 自作の標準→小型→前ずれケースで、調整操作と設定の往復を確かめる。
2. A01とA02を読み込み、補正ゼロの正面／横／上方画像と、狙う頭頂位置を記録する。
3. 一度に一軸ずつ調整し、前後・左右・高さ・サイズの採用値をJSONへ保存する。
4. 頭の左右±60度、上下±30度、屈みを試す。頭ローカル／ワールドの補正を比べる。
5. 同じJSONを読み直して再現性を確認する。アバターを切り替えたら、そのまま適用すべきか再調整すべきかを記録する。
6. 次段階でXRiftの装着・通常歩行・ride・解除へ接続。前後の三人称、ミラー／撮影、他者画面を比べる。
7. 最後にQuestの頭追跡と、2人以上で対象が混ざらないことを確認する。

## 確認基準

- コアでは指定した頭＋オフセットからのずれ1mm以内、設定の書出し→再読込で同じ位置。実機ではフレーム同期由来の遅延を別に測る。
- 見た目は狙った頭頂・帽子からの距離を基準に人が判断する。数値が正しくても、前ずれ・めり込み・読みにくさがあれば未合格。
- 水平維持では頭を傾けても文字が傾かない。カメラ向き表示でもプレイヤーの操縦方向を変えない。
- カメラ・アバターの骨・他人の表示を変更しない。対象不明なら表示を保留する。

## 実験記録

`docs/experiment-record-template.md`をコピーし、avatar_id／環境／入力補正／前後画像／判断を残します。補正JSONは数値設定だけを保存し、VRM・私有モデルの画像は公開してよい範囲を確認してから共有してください。

## 次に育てる順

P0: A02の前ずれ再現と調整しやすさ → P1: アバター別プロファイルと切替 → P2: XRiftの作業中／離席中の手動ステータス共有 → P3: 自動離席判定・VR操作。

アイテムの周囲へ常時大きなUIを置かず、調整は専用の検証画面から始めます。
