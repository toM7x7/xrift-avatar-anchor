# 初期版の状態

2026-10-25。頭上プロペラv9から分離した探索用の初期版です。

| 確認対象 | 状態 |
|---|---|
| 単体テスト | 4件成功 |
| 型宣言の利用例・デモビルド | npm run verify成功 |
| デモの自作骨格 | Playwright CLIの6確認項目が成功 |
| 提供された実VRMのローカル読込 | 1体確認。ファイル・その画像・実ファイル名は非同梱 |
| 新ライブラリを実XRiftへ接続 | 未確認 |
| 別作者の実VRM複数体／VRM両世代 | 未確認 |
| Quest実機／他者視点／複数人 | 未確認 |

ブラウザ検証ではページ例外なし、非GETリクエストなしを確認しました。単体／自作骨格の成功を、実VRMやQuestの一括保証にはしません。デモのVRM読込はraw humanoidの簡易操作であり、XRiftのフルアバターランタイム・アニメーション・spring boneの再現ではありません。

今回の切り出しでは既存のhead-propeller-rideや公開アイテムを変更していません。ライブラリのnpm公開・XRiftへの新規配布は行っていません。

## 残る課題

- A02（実際に前へずれた小型VRM）で、見た目の頭頂への合わせを検証する。
- オフセットのモデル別プロファイル、名前・頭頂・帽子・文字表示の基準を整理する。
- XRift所有者アダプターは名前・ホスト慣習に依存するため、対象明示の入口を優先する。
- 非一様拡縮と回転によるshearのある親は未対応。
